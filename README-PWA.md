# LinguaDaily PWA

This V3 build keeps the existing LinguaDaily application and adds a polished installable PWA layer.

## Included
- Installable `manifest.webmanifest`
- Registered service worker at `/sw.js`
- Offline shell caching
- Static language-data caching after first successful load
- App-store style icon set from 16px through 1024px
- Maskable and standard PWA icon declarations
- Apple touch icon metadata
- Standalone app display on supported mobile/desktop browsers

Open the deployed site in a supported browser and use the browser's **Install app** / **Add to Home Screen** action.
